# 实验与模型验证脚本

日常使用请按根目录 README 启动知识库工作台，无需逐个运行编号脚本。这些脚本用于独立验证解析、检索和向量库行为，不是一条可以连续执行的安装流程。

## 运行前提

- 启用已安装 `requirements.txt` 的 Python 环境，并在项目根目录执行命令。
- 部分脚本读取 `data/documents/南京信息工程大学章程.docx`。该文件不随仓库分发，需要自行准备有权使用的资料；替换资料后，章程条款相关输出也会变化。
- 嵌入和重排实验可能从模型库下载权重，或读取本地模型缓存。
- Chroma 实验可能写入 `data/chroma_db/`；不要直接对需要保留的索引运行实验。

## 脚本分组

| 编号 | 内容 | 主要前提 |
| --- | --- | --- |
| 02–08 | DOCX 读取、章节解析、LangChain 文档及切分 | 部分脚本需要本地章程 |
| 09–17 | 向量化、召回对比、BM25、RRF、重排与父子片段 | 按脚本准备文档及模型 |
| 18–23 | 检索模块与组合流水线 | 本地章程及对应模型 |
| 24–29 | Chroma、向量一致性、文档与分块标识 | 部分脚本创建索引，部分读取指定集合 |
| 30 | 固定本地模型并校验参考向量 | 已有 `nuist_charter_v1` 集合和 `chunk_30` 参考记录 |
| 31 | 知识库真实模型验证 | 嵌入模型；`--hybrid` 还需要重排模型 |

运行前先查看脚本顶部及其中的文件路径、模型名称和集合名称。特别是 `30_pin_embedding_model.py` 会保存模型到 `data/models/bge-small-zh-v1.5`，不应用于初始化空仓库。

## 推荐验证入口

```powershell
# 接口与业务回归，不需要模型权重或真实大模型密钥。
python -m unittest discover -s tests -v

# 使用独立临时数据验证本地模型与 Chroma。
python scripts/31_smoke_knowledge.py
python scripts/31_smoke_knowledge.py --hybrid
```

脚本 31 不改动应用现有索引，也不调用大模型 API。临时目录在成功输出中显示；Chroma 可能持有文件句柄，请在进程退出后按需手动清理。
